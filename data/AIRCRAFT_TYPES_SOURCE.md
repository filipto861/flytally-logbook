# Aircraft type catalogue source

FlyTally bundles an aircraft-type reference derived from the Mictronics aircraft-database project.

Source: `Mictronics/aircraft-database` → `icao_aircraft_types.zip`
License: Open Data Commons Attribution License (ODC-By)
Upstream: https://github.com/Mictronics/aircraft-database

The upstream repository states that exports are updated once per week. FlyTally treats this catalogue as an aircraft identity aid only. ICAO type designators do **not** determine Part-FCL class (SEP/TMG/MEP/SET/etc.); class remains a separate user-confirmed logbook field.

Manual aircraft entry remains supported for types absent from the catalogue.
