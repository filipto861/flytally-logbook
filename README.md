# Letový zápisník Streamlit

Verze: v0.49

## v0.49 – Přehled letů 2.0

- Přepracovaná stránka `Lety` pro každodenní práci se zápisníkem.
- Nové zaměřené filtry: rok, evidence, imatrikulace, letiště, funkce, třída, GPS, stav a trasa.
- Nové řazení: nejnovější, nejstarší, ID sestupně, nejdelší Block Time a nejvyšší náklady.
- Seznam letů nově ukazuje stav záznamu: `OK`, `Pozor`, `Chyba`.
- Stav vychází ze stejné kontroly logbookových pravidel jako při přidání/editaci letu.
- Zachované rychlé akce v seznamu: `Detail`, `Edit`, `GPS`.
- Zachované opravené formátování tlačítek ze v0.48.1.
- Rychlé hledání v tabulce zůstává dostupné nad seznamem.
- Funkčnost mapy, exportu, databáze a KML importu zůstává zachovaná.

## Důležité

Nepřepisovat produkční databázi `data/logbook.sqlite`.
