## Exact implementation contract

- When no file exists, Entry Review renders **one** native `type=button` control `Upload a KML, GPX or CSV track` (same existing `.entry-review-status-link` style). Its synchronous `onClick` calls `sourceInputRef.current?.click()` to open the native picker directly. This is NOT a submit and never saves a flight.
- When the user has selected any file, the **same top control** reads `Change GPS track` and still opens the same picker. No separate visible button under the review. If picker is canceled, no explicit clearing/reset is performed, so the selected `File`/FormData and previous analysis remain consistent. Re-selecting the exact same file may produce no native change event: accept browser default behavior; do not clear the input before picker/cancel.
- Keep **one** DOM `<input name="kml" type="file" required accept=".kml,.gpx,.csv,...">` with unchanged asynchronous `file.text()`, `inspect()`, `fileEpoch` race guard, source state invalidation/reset, split suggestion and form submission path. It is visually clipped and removed from keyboard tab sequence; the top focusable button is the interactive entry point. Avoid `display:none` / Safari constraints. CSS inherits a global 48px input minimum: explicitly override it in the narrowly scoped offscreen rule.
- Remove the redundant visually separate `GPS SOURCE / Upload track` heading and dashed input zone from the form. After file processing, keep the existing informational name/format/points/source/timebasis summary as an `aria-live` status, without introducing another button. Preserve GPS quality/timezone warnings, mandatory evidence, Manual tab, save/certify and other flight-domain logic.
- For an unusable source (less than two GPS points or no parts), the quick review heading explicitly explains that usable track data is needed, while its single `Change GPS track` action allows correction. Existing non-source review issue links (aircraft/role/operation/etc) still use their original direct-to-field behavior; their count no longer includes a redundant file-selection action.
