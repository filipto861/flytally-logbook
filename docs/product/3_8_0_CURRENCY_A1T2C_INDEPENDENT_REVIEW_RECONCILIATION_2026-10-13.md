## Corrected normative acceptance deltas

1. **Eligibility/locking:** lock `deleted_flights` by authenticated `id + user_id`. Revalidate `restored_at`, `purge_after`, exact three archived JSON values and original owner IDs **inside** the same transaction. No absent `flights` row lock or invented timestamps.
2. **Zero-write vs failure:** expired/already-restored/stale eligibility must have explicit stable response semantics; eligible archive that fails natural-key check is an explicit duplicate conflict. A reserved sequence value is **not** proof that an INSERT succeeded. Corrupt ownership/monetary snapshot => fail closed, full rollback.
3. **Children:** explicit allowlisted v20/v21 projection preserving `currency` including CZK when present, `amount_minor` integer, encoding/exponent and exact decimal hourly price text. Reparent to fresh numeric IDs and assert both **row count and all mapped content**. No filtering or arbitrary defaults for invalid archived rows. Source `track_points` absence remains a separately documented evidence limitation; do not claim restoration of those data.
4. **Concurrency:** exact same-trash ID serialization on two independent sessions is mandatory. Two different trash rows sharing normalized natural key must be tested, not “fixed” by an index keyed on nonexistent fields or original IDs. A normalized-key advisory lock limited to restore callers is a **possible design candidate** pending actual PG16 tests, not a guarantee against unrelated flight writers. If product requires global uniqueness across all Add/Edit/Restore paths, escalate to owner for explicit business-rule decision.
5. **Critical checks:** use always-on `RAISE EXCEPTION` / constraints, never `ASSERT` as sole guard. Preserve source/DB certification and participation rules. Probe PG16 SQL syntax and local psql batching before proposing HTTP runtime integration.
6. **Test mapping:** strengthen T2c-02 (exact rates vs integer minor-unit expenses; include legitimately recorded CZK), -09 (forced late child failure rollback), -10/-11 (two-session race), -12 (malformed JSON + nullable optional children + zero children), -13 (fresh unique remapping without max-ID promise), -14 (temp scope + unconditional error SQLSTATE), -16 (nonproduction authorized pooled/direct HTTP behavior and propagation).
