## Apple Design V2 deep adaptation (proposal)
The user specifically requested frequent Apple Design use throughout Logbook UI. This proposal adds a dedicated apple-design skill and a full 17-domain project playbook based on the archive's 290-line apple-design/SKILL.md. It preserves source categories, constraints and illustrative algorithms (velocity handoff, momentum projection, rubber-banding) in source-backed adapted language, and differentiates them from verified runtime behavior and approved FlyTally defaults. This is NOT a verbatim vendor skill install and does not import Swift/iOS frameworks or new JS libraries. The source contains a canned first-invocation response; it is intentionally NOT an operative instruction in FlyTally.

## How this repo uses them
No source skills are copied verbatim or automatically installed; the V2 proposed apple-design playbook adapts all 17 original content categories. Our project-local skills ADAPT selected principles:
- Design details, interaction feedback, restraint, typography and motion: design-engineering and ui-ux-design.
- Safe areas, multi-input mobile, viewport and real-device validation: mobile-ipad.
- Plausible worst-case fixture testing, animation assessment and explicit findings: ui-quality-audit.
- Existing source/coverage and domain skills always have priority; third-party text is methodological inspiration, not a new application dependency or product authority.

Not adopted by default: Swift/Expo code, Sonner, UI-library selection, automatic prototype changes, source skills' introductory-response prompts, unreviewed animation defaults or unfiltered command instructions.

## Design Quality V2 — additional sources evaluated 2026-10-24

- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines): read-only code and interaction review (keyboard, semantics, focus, responsive, feedback, reduced motion).
- [Nutlope Hallmark](https://github.com/Nutlope/hallmark): *audit/study* anti-generic review, not theme generation/redesign or blind global CSS rules.
- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): reference patterns for tables/dashboards, never replace FlyTally color/tokens or run its installer.
- [Kombai Gallery](https://kombai.com/gallery/web/): view public examples for information hierarchy; do not copy templates, source code or assets without license.
- [shadcn/ui](https://ui.shadcn.com/docs): study narrowly selected component behavior; not installed or mandated.
- Emil Kowalski remains adapted via existing project skills; **do not install a second copy**.
