# v1.63.0 — Helicopter support

## Scope

- Dedicated `HELICOPTER` regulatory context in aircraft profiles and flight records.
- Universal flight entry adapts to helicopter operations without introducing a separate Add Helicopter page.
- Explicit pilot-flying take-off, approach and landing evidence for Part-FCL recency calculations.
- LAPL(H) FCL.140.H recency evaluated separately for each specific helicopter type.
- Signed instructor refresher evidence and proficiency-check alternative route.
- FCL.060 helicopter passenger currency, including night movement and current IR(H) handling.
- LAPL(H), PPL(H), CPL(H), ATPL(H) and helicopter qualification support in Licences.
- Helicopter Recency panel integrated alongside Aeroplane and SPL recency.
- Portable backup format v10 includes helicopter recency evidence.

## Regulatory safety boundaries

- Helicopter types are not modelled as aeroplane class ratings.
- Flight experience from different helicopter types is not pooled for FCL.140.H.
- Unsigned DUAL or supervised-solo evidence does not satisfy the LAPL(H) experience route.
- FCL.060 uses explicit pilot-flying movement evidence rather than inferred landings.
- Existing SPL / Part-SFCL and aeroplane Part-FCL logic remains separate.
